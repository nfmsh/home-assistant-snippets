
# Frigate GenAI Event Browser

A Home Assistant dashboard card for viewing and browsing recent Frigate GenAI events.

The event browser listens to Frigate's `frigate/reviews` MQTT topic and stores the 10 most recent GenAI results in a Home Assistant template sensor.

You can then browse backwards and forwards through those events directly from your dashboard.

## Features

- Displays Frigate GenAI event thumbnails
- Shows the GenAI-generated event title and scene description
- Shows camera name and event time
- Stores the 10 most recent GenAI events
- Previous, Latest and Next navigation
- Displays the current position in the event history
- Shows threat level when greater than zero
- Shows AI confidence when below 90%
- Works with Frigate GenAI regardless of the configured AI provider

## Requirements

- Home Assistant
- Frigate with GenAI enabled
- Frigate connected to the same MQTT broker as Home Assistant
- MQTT integration configured in Home Assistant
- [card-mod](https://github.com/thomasloven/lovelace-card-mod)

The card uses standard Home Assistant Button and Markdown cards. `card-mod` is used for the compact navigation buttons and thumbnail styling.

## How it works

Frigate publishes review updates to:

```text
frigate/reviews
```

When a review receives GenAI metadata, the MQTT-triggered template sensor stores the event details in its `events` attribute.

The newest event is stored at index `0`. Up to 10 events are retained.

An `input_number` helper tracks which event is currently displayed.

The navigation controls work as follows:

- **Previous** moves backwards through older events
- **Latest** returns directly to index `0`
- **Next** moves towards newer events

## Installation

There are two installation methods.

### Option 1: Home Assistant package

This is the recommended method.

Copy:

```text
package/frigate_genai_event_browser.yaml
```

into your Home Assistant packages directory.

For example:

```text
/config/packages/frigate_genai_event_browser.yaml
```

Your Home Assistant configuration must have packages enabled:

```yaml
homeassistant:
  packages: !include_dir_named packages
```

Restart Home Assistant after adding the package.

The package creates:

- `sensor.frigate_latest_ai_event`
- `input_number.frigate_ai_event_index`
- `script.frigate_ai_previous`
- `script.frigate_ai_next`

### Option 2: Manual installation

If you prefer to integrate the configuration into your existing Home Assistant YAML, use the files in the `manual` directory.

#### Template sensor

Merge:

```text
manual/template-sensor.yaml
```

under your existing `template:` configuration.

Do not create a second top-level `template:` key if one already exists.

#### Helper

Either merge:

```text
manual/helper.yaml
```

into your existing `input_number:` configuration, or create a Number helper through the Home Assistant UI with:

- Name: `Frigate AI Event Index`
- Minimum: `0`
- Maximum: `9`
- Step: `1`

The resulting entity must be:

```text
input_number.frigate_ai_event_index
```

#### Scripts

Merge:

```text
manual/scripts.yaml
```

into your existing `scripts.yaml`.

Restart Home Assistant or reload the appropriate YAML configuration after making the changes.

## Add the dashboard card

Copy the contents of:

```text
card.yaml
```

into a Home Assistant Manual card.

The card will initially display:

```text
No Frigate GenAI events stored yet.
```

Once Frigate publishes a GenAI review event, it will appear automatically.

## Event history

By default, the template sensor stores the most recent **10 events**.

This is controlled by:

```jinja
{{ ([event] + old)[:10] }}
```

and the navigation helper has a maximum value of `9`.

If you change the history size, remember to change both values accordingly.

For example, for 20 events:

```jinja
{{ ([event] + old)[:20] }}
```

and:

```yaml
max: 19
```

## GenAI providers

The event browser does not communicate with an AI provider itself.

It displays GenAI metadata already generated by Frigate, so it can be used with any GenAI provider supported by your Frigate installation.

The AI provider is configured entirely within Frigate.

## Notes

The event history is stored as an attribute of the Home Assistant template sensor. It is intended as a lightweight recent-event browser rather than a permanent event archive.

Frigate remains the source of the underlying review events and media.

## Troubleshooting

### No events appear

Check that Frigate is publishing to the same MQTT broker used by Home Assistant.

In Home Assistant, listen to:

```text
frigate/reviews
```

and confirm that GenAI events are being received.

### Thumbnail does not appear

The card retrieves the review thumbnail through the Frigate Home Assistant integration using:

```text
/api/frigate/notifications/<review_id>/<camera>/review_thumbnail.webp
```

Make sure the Frigate integration is installed and working in Home Assistant.

### Navigation does not work

Check that these entities exist:

```text
input_number.frigate_ai_event_index
script.frigate_ai_previous
script.frigate_ai_next
```

Also check that `sensor.frigate_latest_ai_event` contains an `events` attribute.
